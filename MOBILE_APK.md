# Капибара-рыцарь для Android

Скачайте `Capybara-knight-android.apk` из файлов этого релиза и откройте на Android. Приложение запускает встроенную историю без компьютера и Expo Go. Поверните телефон или планшет горизонтально.

У каждого игрока своё сохранение. Профили, решения и найденные предметы сохраняются на устройстве после закрытия приложения. Устанавливайте новую APK поверх предыдущей: при удалении приложения локальные данные могут быть удалены. Данные браузера и APK хранятся отдельно.

Это предварительная версия для проверки на устройствах, с тестовой подписью. Для Google Play используется отдельная production-сборка с постоянным ключом владельца.

Вместе с APK опубликован файл SHA-256. Перед публикацией проверяются подпись, запуск на Android-эмуляторе, восстановление профиля и реплики после перезапуска, а также блокировка вертикального экрана.
